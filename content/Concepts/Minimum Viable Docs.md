The "Minimum Viable Documentation" or "Documentation Triage" refers to prioritizing the most inmportant documentation content so that if you run out of time you don't have to delay releases because of missing crucial information. It means accepting that you won’t be able to do it all. Basically:

>**Don’t strive for perfection but rather documentation that is _good enough_.**
